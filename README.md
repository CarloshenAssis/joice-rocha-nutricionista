# Joice Rocha — Nutricionista

Site institucional responsivo da nutricionista Joice Rocha.

## Conteúdo do projeto

- `index.html` — página completa, incluindo estilos e interações.

## Como visualizar

Abra o arquivo `index.html` em um navegador.

O projeto é estático e pode ser publicado diretamente no GitHub Pages, Netlify,
Vercel ou em qualquer hospedagem que aceite arquivos HTML.

## GitHub Pages

1. Envie os arquivos para a raiz do repositório.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
